
# ВЕКТОРЫ И СТРОКИ В C++

## std::vector

### Что такое вектор?

**Вектор (`std::vector`)** — это динамический массив из стандартной библиотеки C++.

**Основные характеристики:**
- Хранит элементы в непрерывном фрагменте памяти
- Предоставляет быстрый доступ по индексу
- Позволяет эффективно добавлять элементы в конец
- Автоматически меняет размер при необходимости
- Гарантирует отсутствие утечек памяти

### Подключение библиотеки

```cpp
#include <vector>
```

## Объявление и инициализация

### Синтаксис

```cpp
std::vector<тип> имя_вектора;
```

### Способы создания

```cpp
std::vector<int> v1;                  
std::vector<int> v2(5);               
std::vector<int> v3(5, 10);             
std::vector<int> v4 = {1, 2, 3, 4, 5};  
std::vector<std::string> v5(3, "hi");   
```

## Доступ к элементам

### По индексу (без проверки)

```cpp
std::vector<int> data = {1, 2, 3, 4, 5};
int a = data[0];    
int b = data[4];    
data[2] = 10;        
```

### С проверкой (через at)

```cpp
std::cout << data.at(0) << '\n';   
std::cout << data.at(42) << '\n';  
```

### Первый и последний элемент

```cpp
std::cout << data.front() << '\n';  
std::cout << data.back() << '\n';   
```

## Размер и проверка

### size() — количество элементов

```cpp
std::cout << data.size() << '\n';
```

### empty() — проверка на пустоту

```cpp
if (data.empty()) {
    std::cout << "Вектор пуст\n";
}
```

## Итерация по элементам

### Range-for (C++11)

```cpp
for (int elem : data) {
    std::cout << elem << " ";
}
```

### По индексам 

```cpp
for (size_t i = 0; i != data.size(); ++i) {
    std::cout << data[i] << " ";
}
```

**Правила:**
- Используем `!=` вместо `<`
- Используем префиксный `++i`
- `size()` возвращает беззнаковый тип `size_t`

### Аккуратнее в этом 

```cpp
// Неправильно
for (size_t i = 0; i < data.size() - 1; ++i) { ... }

// Правильно
for (size_t i = 0; i + 1 < data.size(); ++i) { ... }

// Правильно
for (int64_t i = 0; i < std::ssize(data) - 1; ++i) { ... }
```

## Добавление и удаление

### push_back() — добавить в конец

```cpp
std::vector<int> data;
data.push_back(10);
data.push_back(20);
```

### pop_back() — удалить с конца

```cpp
data.pop_back();   // удаляет последний элемент
```

### clear() — удалить всё

```cpp
data.clear();   // вектор становится пустым
```

## Полный пример

```cpp
#include <iostream>
#include <vector>

int main() {
    int x;
    std::vector<int> data;
    
    // Читаем числа до конца ввода
    while (std::cin >> x) {
        data.push_back(x);
    }
    
    // Удаляем нули в конце
    while (!data.empty() && data.back() == 0) {
        data.pop_back();
    }
    
    // Выводим результат
    for (int elem : data) {
        std::cout << elem << " ";
    }
    std::cout << '\n';
}
```

## Таблица методов

| Метод | Описание | Сложность |
|-------|----------|-----------|
| `push_back(x)` | Добавить в конец | O(1) |
| `pop_back()` | Удалить с конца | O(1) |
| `size()` | Количество элементов | O(1) |
| `empty()` | Проверка на пустоту | O(1) |
| `clear()` | Удалить всё | O(n) |
| `at(i)` | Доступ с проверкой | O(1) |
| `operator[](i)` | Доступ без проверки | O(1) |
| `front()` | Первый элемент | O(1) |
| `back()` | Последний элемент | O(1) |

## Резерв памяти

Вектор хранит элементы в памяти в виде **непрерывной последовательности**, друг за другом. При этом в конце последовательности резервируется дополнительное место для быстрого добавления новых элементов. Когда этот резерв заканчивается, при вставке очередного элемента происходит **реаллокация**: элементы вектора копируются в новый, более просторный блок памяти.

Реаллокация — довольно дорогая процедура, но если она происходит достаточно редко, то её влияние незначительно. Можно доказать, что если размер нового блока выбирать **в два раза больше** предыдущего размера, то амортизационная сложность добавления элемента будет **константной**.

Текущий резерв вектора можно узнать с помощью функции `capacity` (не путайте её с функцией `size`).

 <img width="522" height="589" alt="image" src="https://yastatic.net/s3/education-portal/media/C_4_4ac318ee9f_146cbfc8ee.svg" />: схема с capacity() и size()

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> data = {1, 2};
    std::cout << data.size() << "\t" << data.capacity() << "\n";
    
    data.push_back(3);
    std::cout << data.size() << "\t" << data.capacity() << "\n";
    
    data.push_back(4);
    std::cout << data.size() << "\t" << data.capacity() << "\n";
    
    data.push_back(5);
    std::cout << data.size() << "\t" << data.capacity() << "\n";
}
```

Вывод этой программы:

```
2	2
3	4
4	4
5	8
```

Видно, что размер вектора увеличивается на единицу, а резерв удваивается после исчерпания. Так, при добавлении четвёрки используется имеющаяся в резерве память, а при добавлении тройки и пятёрки происходит реаллокация.

<img width="522" height="589" alt="image" src="https://yastatic.net/s3/education-portal/media/C_5_bea6b5948b_0684ef4144.svg" />

Иногда требуется заполнить вектор элементами, причём число элементов известно заранее. В таком случае можно сразу зарезервировать нужный размер памяти с помощью функции `reserve`, чтобы при добавлении элементов не происходили реаллокации. Пусть, например, нам сначала задаётся число слов, а потом сами эти слова, и нам требуется сложить их в вектор:

```cpp
#include <iostream>
#include <string>
#include <vector>

int main() {
    std::vector<std::string> words;
    
    size_t words_count;
    std::cin >> words_count;
    
    words.reserve(words_count);
    
    for (size_t i = 0; i != words_count; ++i) {
        std::string word;
        std::cin >> word;
        words.push_back(word);
    }
}
```

Если передать в `reserve` величину меньше текущего резерва, то ничего не поменяется — резерв останется прежним.

Функцию `reserve` не следует путать с функцией `resize`, которая меняет количество элементов в векторе. Если аргумент функции `resize` меньше текущего размера, то лишние элементы в конце вектора удаляются. Если же он больше текущего размера, то при необходимости происходит реаллокация и в вектор добавляются новые элементы с дефолтным значением данного типа.

```cpp
#include <vector>

int main() {
    std::vector<int> data = {1, 2, 3, 4, 5};
    
    data.reserve(10);  
    data.resize(3);   
    data.resize(6);   
}
```

## Многомерные векторы

Воспользуемся вектором векторов, чтобы сохранить таблицу целых чисел. Пусть на вход программы сначала поступают число строк и число столбцов матрицы, а потом — сами элементы построчно:

```cpp
#include <iostream>
#include <vector>

int main() {
    size_t m, n;
    std::cin >> m >> n;  
    
    std::vector<std::vector<int>> matrix(m, std::vector<int>(n));
    
    for (size_t i = 0; i != m; ++i) {
        for (size_t j = 0; j != n; ++j) {
            std::cin >> matrix[i][j];
        }
    }
    
    for (size_t i = 0; i != m; ++i) {
        for (size_t j = 0; j != n; ++j) {
            std::cout << matrix[i][j] << "\t";
        }
        std::cout << "\n";
    }
}
```

В этом примере мы заранее создали матрицу из нулей, а потом просто меняли её элементы.

## Сортировка вектора

Рассмотрим задачу — отсортировать вектор по возрастанию. Для этого в стандартной библиотеке в заголовочном файле `algorithm` есть готовая функция `sort`. 

```cpp
#include <algorithm>
#include <vector>

int main() {
    std::vector<int> data = {3, 1, 4, 1, 5, 9, 2, 6};
    std::sort(data.begin(), data.end());
    
    // получим вектор 1, 1, 2, 3, 4, 5, 6, 9
}
```

В функцию `sort` передаются так называемые **итераторы**, ограничивающие рассматриваемый диапазон. В нашем случае мы передаём диапазон, совпадающий со всем вектором, от начала до конца. Соответствующие итераторы возвращают функции `begin` и `end`. Итераторы можно считать обобщёнными индексами.

Для сортировки по убыванию можно передать на вход обратные итераторы `rbegin()` и `rend()`, представляющие элементы вектора в перевёрнутом порядке:

```cpp
std::sort(data.rbegin(), data.rend());  // 9, 6, 5, 4, 3, 2, 1, 1
```

В C++20 доступен более элегантный способ сортировки через `std::ranges::sort`:

```cpp
#include <algorithm>
#include <vector>

int main() {
    std::vector<int> data = {3, 1, 4, 1, 5, 9, 2, 6};
    
    std::ranges::sort(data);  
}
```

Для сортировки по умолчанию используется сравнение элементов с помощью оператора `<`. Этот оператор работает и для самих векторов: они сравниваются **лексикографически**. Поэтому можно без проблем отсортировать.

## Строки

Контейнер `std::string` можно рассматривать как особый случай вектора символов `std::vector<char>`, имеющий набор дополнительных функций. В частности, у строки есть все те же рассмотренные нами функции, что и у вектора. Рассмотрим некоторые специфические функции строки:

```cpp
#include <iostream>
#include <string>

int main() {
    std::string s = "Some string";
    
    s += ' ';        
    s += "functions";  
    std::cout << s << "\n";  
    
    // подстрока "string" из 6 символов начиная с 5-й позиции
    std::string sub1 = s.substr(5, 6);
    // подстрока "functions" с 12-й позиции и до конца
    std::string sub2 = s.substr(12);
    
    
    size_t pos1 = s.find(' ');           
    size_t pos2 = s.find(' ', pos1 + 1);  
    size_t pos3 = s.find("str");         
    size_t pos4 = s.find("#");            
}
```

Вставку, замену и удаление подстрок можно сделать через указание индекса начала и длины подстроки:

```cpp
#include <iostream>
#include <string>

int main() {
    std::string s = "Some string functions";
    
    s.insert(5, "std::");
    std::cout << s << "\n";  // Some std::string functions
    
    s.replace(0, 4, "Special");
    std::cout << s << "\n";  // Special std::string functions
    
    s.erase(8, 5);  // Special string functions
}
```

Аналогичные действия для других контейнеров можно сделать через итераторы. Мы рассмотрим такие примеры в одном из следующих параграфов.

В C++20 появились удобные функции `starts_with` и `ends_with` для проверки префикса или суффикса строк:

```cpp
#include <iostream>
#include <string>

int main() {
    std::string phrase;
    std::getline(std::cin, phrase);
    
    if (phrase.starts_with("hello")) {
        std::cout << "Greeting\n";
    }
    
    if (phrase.ends_with("bye")) {
        std::cout << "Farewell\n";
    }
}
```
